# Pop Hive — play

**Play:** https://irvanfaturohman.github.io/pop-hive-play/

Prototype puzzle game (works on desktop and mobile). Tap the front shooter of a lane: it rides the
conveyor around the board and shoots balloons of its own color. Don't let the parking fill up!

This repository only contains the built game. Sound effects and music are licensed third-party assets
used inside the game; do not redistribute the audio files separately.
